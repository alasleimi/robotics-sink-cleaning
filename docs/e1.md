# E1 in the simulator

E1 is joint 3's angle, in radians. The inverse-kinematics solver fixes that joint and solves the remaining six within their limits. It never silently relaxes an explicit E1 request.

```java
Frame target = SunriseConnector.getTcpFrame();
target.setRedundancyInformation(robot,
    new LBRE1Redundancy().setE1(Math.toRadians(20)));
tool.move(BasicMotions.lin(target));
```

This changes the elbow configuration while holding the TCP pose, if the path is reachable. `ptp(target)` reaches the same constrained endpoint through joint interpolation; the TCP need not remain fixed along that path.

- Cartesian PTP uses target E1 and Status, defaulting missing values to the starting configuration. LIN interpolates starting-to-target E1 and retains starting Status. Relative LIN retains starting E1.
- Taught/current frames and forward kinematics return redundancy metadata. Save/load preserves it, including E1-only requests. Explicit E1 overrides a saved joint seed. Old seed-only simulator recordings remain readable.
- Status is computed from wrist position relative to A1, the sign of A4, and the sign of A6. The numerical solver checks the requested configuration. Turn is retained as metadata and ignored for iiwa motions, as documented by KUKA.
- Frame metadata applies to the named robot; unrelated device entries are ignored. The direct `getInverseKinematicFromFrameAndRedundancy` API requires E1 for this robot and refers to its flange.

The model's flange attachment corrects robosuite's gripper-facing rotation and its 1 mm distance difference. Regression tests compare it to Arne's independent `stuff/iiwa-model.py` at zero, the front posture, and 30 varied joint configurations.

Tests also cover fixed-TCP elbow changes, Status branches, continuous LIN, Java save/replay, and unreachable E1 errors. Complete Sunrise trajectory timing, singularity handling, and hardware equivalence are not claimed.

References: the bundled KUKA SDK `LBRE1Redundancy` Javadoc ([mirror](https://www.iway2.net/kuka/com/kuka/roboticsAPI/deviceModel/LBRE1Redundancy.html)); KUKA Sunrise.OS manual, sections 14.10 and 15.7 ([manufacturer-authored manual mirror](https://www.scribd.com/document/353521335/KUKA-SunriseOS-1-5-En)).
