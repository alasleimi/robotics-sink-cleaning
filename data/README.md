# Data

Small examples and format descriptions can be committed here. Large/raw demonstrations go in `recordings/`, which is ignored by Git. Shared recording storage has not been chosen.

Each recording contains `samples.csv`, `metadata.json`, and the captured tool/application XML. Units, frame definitions and commands are in [the demonstration guide](../docs/demonstrations.md). Preserve raw recordings before preprocessing.

`examples/sink` contains five explicitly synthetic simulator demonstrations and the KMP/TP-KMP pilot results. These are small enough to keep with the project; no human or real-robot recordings are included.
